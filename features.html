Security Features

Ed25519 Signatures

RFC 8032 compliant Ed25519 signing and verification with embedded Python implementation. Supports keypair generation, seed-based public key derivation, batch verification, and artifact integrity checks with quarantine.

SBOM generation

Software Bill of Materials generation with SHA256 hashes and file sizes. Compliance reporting against EU AI Act, ISO 42001, and NIST AI RMF controls.

Compliance Scoring

Automated compliance matrix evaluation across 8 controls mapping to EU AI Act, ISO 42001, and NIST AI RMF. Markdown and JSON report generation with --strict mode.

KMS Key Rotation

Key management control verifying kms_key_id presence and key rotation enablement. Multi-target evidence merging for audit scenarios.
