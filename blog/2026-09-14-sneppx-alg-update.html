sneppx-alg v0.5 released

2026-09-14

Category: Core Library

What's New

  • elementwise_affine parameter added to LayerNorm - allows disabling weight and bias affine transformation
  • verify_artifact() convenience function in signature.py - combined hash + Ed25519 signature check
  • KMS control added to sneppx-audits - key rotation verification for compliance
  • Higher-order AD improvements for SmoothL1/Huber loss functions
  • Sparse tensor N-D support (generalized from 2-D only)

Technical Details

# Example: LayerNorm with elementwise_affine=False
ln = LayerNorm(normalized_shape=64, elementwise_affine=False)
out = ln(input_tensor)  # No weight/bias applied

Upgrade Guide

  1. Update LayerNorm constructor to include elementwise_affine parameter
  2. Set elementwise_affine=False if you previously disabled affine transforms
  3. Verify forward pass outputs match expected behavior
