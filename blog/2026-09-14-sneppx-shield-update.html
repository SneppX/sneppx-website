sneppx-shield verify_batch()

2026-09-14

Category: Security

What's New

  • verify_batch() function added to signature.py - batch Ed25519 signature verification
  • Accepts paths list, optional sig_paths (scalar or list), optional public_key (scalar or list)
  • Returns list of (ok: bool, detail: dict) tuples, one per artifact
  • Combines with verify_artifact() for single-artifact convenience

Usage Example

# Verify multiple artifacts at once
results = verify_batch([
    "model1.pt",
    "model2.pt",
    "model3.pt"
], sig_paths=["model1.sig", "model2.sig", "model3.sig"])

for ok, detail in results:
    if ok:
        print(f"Verified: {detail.get('signer', 'unknown')}")
    else:
        print(f"Failed: {detail.get('error', 'unknown')}

Batch Verification Workflow

  1. Collect all model artifacts and their signature files
  2. Call verify_batch(paths, sig_paths) with matching lists
  3. Process results - quarantine failed verifications
  4. Generate compliance reports for passed verifications
